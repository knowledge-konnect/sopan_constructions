## Recommendation

Before publishing or reusing these assets externally:

1. Confirm each image with the original photographer or client.
2. Replace any unverified image with licensed stock or owned project photography.
3. Add the exact photographer name, source URL, and licence type for each final asset.

> At present, these images should be treated as repository-local placeholders until a proper rights record is available.
